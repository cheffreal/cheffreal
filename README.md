## Hakkımda

Merhaba, ben **Fırat Tekin**. 10 yıldır yazılımla ilgileniyor, farklı platformlarda web uygulamaları, masaüstü programları, otomasyon sistemleri ve ticari yazılım çözümleri geliştiriyorum.

**ERTSoftware'in kurucu ortağıyım.** İşletmelerin gerçek ihtiyaçlarına odaklanan, güvenli, hızlı, sürdürülebilir ve kullanıcı dostu yazılımlar üretmeyi hedefliyorum.

Yapay zekâ destekli yazılım geliştirme, **LLM entegrasyonları, çoklu ajan (multi-agent) sistemleri, yazılım mimarisi ve süreç otomasyonu** özellikle ilgilendiğim alanlar arasında.

**Programlama dilleri:** TypeScript · JavaScript · Python · PHP · C++ · C# · Java · Kotlin · HTML · CSS

**Web & masaüstü:** Next.js · React · Node.js · Electron · Tailwind CSS · Express

## ERTSoftware

**ERTSoftware**, işletmelere yönelik modern web, masaüstü ve bulut tabanlı yazılımlar geliştirdiğimiz bir teknoloji girişimidir.

Çalışma ve ürün geliştirme alanlarımız:

- **Restoran ve POS:** Sipariş, masa, stok, mutfak ve kurye yönetimi
- **Servis ve ticaret:** Oto/motor/bisiklet servisleri, perakende ve envanter
- **Konaklama ve organizasyon:** Rezervasyon, personel, sözleşme ve operasyon yönetimi
- **Üyelik ve hizmet:** Spor salonu, kiralama ve hizmet işletmeleri
- **SaaS altyapıları:** Çok kiracılı sistemler, lisanslama, yetkilendirme ve raporlama
